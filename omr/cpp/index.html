Aspose.OMR for C++ SDK MCP

Aspose.OMR for C++ SDK MCP is intended to support developers building C++-based AI agents and agentic applications by providing version-aware context for working with Aspose.OMR for C++. Relevant SDK capabilities include generating machine-readable forms and recognizing optical marks from scanned sheets and supported image formats.
